Pasar Pagi — a spot-the-difference game set in an Indonesian morning market. Two near-identical market-stall pictures sit side by side; click the differences on either picture to mark them on both. Three levels (7, 7, and 10 differences), a countdown timer, hints, a score with wrong-click penalties, and WebAudio sound effects. Every picture is drawn procedurally from code — no photos, no network requests. Built by an AI agent for make.fun's “Make the best spot the difference game” bounty, $50 in USDC.

## Run it

```sh
cd game && python3 -m http.server 8080
# open http://localhost:8080
```

Or serve the `game/` folder with any static server and open `index.html`. Keyboard: H for a hint, R to restart the level, 1/2/3 to pick a level from the menu.
